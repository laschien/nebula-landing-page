# Nebula Notes — Landing Page

A modern minimal landing page for **Nebula Notes**, a fictional note-taking app designed to help creative thinkers organize ideas among the stars.  
This project was built as a front-end practice exercise focusing on semantic HTML, clean CSS architecture.

---

## Live Demo

<https://laschien.me/nebula-landing-page/>

---

## Project Goals

- Practice writing **semantic, accessible HTML**
- Build a clean, modern layout using **pure CSS**
- Implement elegant UI elements:
  - Modern navigation bar
  - SaaS-style hero section
  - Smooth hover interactions
- Strengthen CSS fundamentals (spacing, typography, layout, components)

---

## **Tech Stack**

| Technology               | Purpose                                |
| ------------------------ | -------------------------------------- |
| **HTML5**                | Page structure & semantics             |
| **CSS3**                 | Layout, styling, and responsive design |
| **Google Fonts (Inter)** | Modern typography                      |
| **Flexbox**              | Layout and alignment                   |

No frameworks, no libraries — just handcrafted HTML and CSS.
